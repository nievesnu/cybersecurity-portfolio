**Finds & Reminders** 
The operating system separates its environment into different areas with different levels of access.
Kernel Space is the highly privileged area of the operating system. It has direct access to the computer's hardware and is where the kernel manages hardware and system resources.
User Space is where regular applications run. Applications have limited permissions to improve security and maintain system stability.

**Important Q's and A's:**
*Which OS space has unrestricted access to your computer's hardware?*: 
`Kernel Space`
*Which OS responsibility manages user accounts, authentication, and permissions?*
`User Management`
