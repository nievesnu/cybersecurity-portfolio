---

 # Documentation Style

 Cada room documentada contiene principalmente:

 - Conceptos aprendidos.
- Herramientas utilizadas.
- Procedimientos importantes.
- Comandos relevantes.
- Respuestas de las preguntas.
- Flags obtenidas cuando corresponda.
- Conclusiones y conocimientos adquiridos.

 La documentación está orientada a registrar **lo que he aprendido y realizado**, no simplemente a almacenar respuestas.
